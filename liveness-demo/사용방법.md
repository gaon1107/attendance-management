# 사진판독 (얼굴 위조 판별) — 사용 방법

> 웹캠/사진 속 얼굴이 **진짜 사람인지, 사진·화면(휴대폰/모니터)인지** 판별하는 AI 모듈 + 테스트용 데모 앱.
> 근태관리 프로젝트에서 개발·검증한 것을 다른 프로젝트에서도 쓸 수 있게 독립 패키지로 정리함 (2026-07-11).

---

## 1. 데모 실행 (비개발자용)

1. 이 폴더에서 **`라이브니스데모_실행.bat` 더블클릭**
2. 검은 서버 창이 뜨고, 5초쯤 뒤 브라우저(http://localhost:3100)가 자동으로 열림
3. 웹캠 촬영 → 진짜/위조 점수 확인. 기준값 슬라이더로 판정선 조절
4. 끝낼 때는 검은 창을 닫으면 됨

※ 처음 받은 PC에서는 먼저 명령창에서 `npm install` 1회 필요 (Node.js 설치돼 있어야 함).
※ `.env` 파일에 얼굴서버(가온 GaonFR) 접속 정보가 들어 있음 — **비밀값이므로 외부 공유 금지.**

---

## 2. 구성 요소

| 파일/폴더 | 내용 |
|---|---|
| `lib/liveness.ts` | **핵심 판독 모듈** — 다른 프로젝트로 가져갈 파일. 얼굴 위치를 받아 진짜 확률(0~1)을 반환 |
| `models/*.onnx` (2개) | 학습된 AI 모델(MiniFASNet V1SE·V2, 각 1.7MB). 판독 모듈이 읽는 데이터 파일 |
| `lib/gaonfr.ts` | 가온 얼굴서버 연동(얼굴 위치 검출용) — 다른 얼굴검출기를 쓰면 불필요 |
| `app/` | 데모 화면(Next.js) — 테스트용, 이식 대상 아님 |
| `NOTICE.md` | 모델 출처·라이선스(Apache-2.0) — **이식하는 프로젝트에도 반드시 같이 복사** |

## 3. 다른 프로젝트에 이식하는 방법 (개발자/AI 에이전트용)

### 3-1. 가져갈 것
1. `lib/liveness.ts` (판독 모듈)
2. `models/MiniFASNetV1SE.onnx`, `models/MiniFASNetV2.onnx` (프로젝트의 `models/` 폴더로)
3. `NOTICE.md` (라이선스 고지 — Apache-2.0이라 상업 사용 가능하되 고지 유지)
4. npm 패키지 설치: `npm install onnxruntime-node sharp`

### 3-2. 호출 방법
```ts
import { analyzeFace } from "./lib/liveness";

// imageBuffer: 사진 원본(JPEG 등) Buffer
// rect: 사진 좌표계의 얼굴 위치 { x, y, width, height } — 얼굴검출기가 알려준 값
const result = await analyzeFace(imageBuffer, rect);
// result.realScore : 진짜 사람일 확률 0~1 (예: 0.97 = 97%)
// result.models    : 모델별 세부 점수(V1SE·V2)
// result.ok=false  : 판독 실패(원인은 서버 로그, message는 사용자용 한국어)
```

### 3-3. 얼굴 위치(rect)는 어떻게 구하나
판독 모듈은 "얼굴이 어디 있는지"를 **직접 찾지 않는다.** 얼굴검출기가 준 상자를 받아서 판독만 한다.
- 근태관리/이 데모: 가온 얼굴서버의 detect API 응답(FaceRect) 사용 (`lib/gaonfr.ts` 참고)
- 다른 프로젝트: 이미 쓰는 얼굴검출기(어떤 것이든)의 상자 좌표를 그대로 넘기면 됨

### 3-4. 실행 환경
- Node.js 서버(Next.js·Express 등 무관), **CPU만으로 동작(GPU 불필요)**, Windows/Linux 모두 가능
- 속도: 사진 1장당 약 30~100ms (검출 제외)
- 모델 파일 경로: `liveness.ts`의 `modelsDir()`가 실행 폴더 기준 `models/`를 찾음 — 위치가 다르면 이 함수만 수정

## 4. ⚠️ 반드시 알아야 할 주의사항

1. **판정 기준값(threshold)은 환경마다 다르다.**
   카메라·조명이 바뀌면 점수 분포가 달라진다. 새 프로젝트에서는 반드시 그 환경의 웹캠으로
   "진짜 얼굴 최저 점수 vs 위조(폰사진 등) 최고 점수"를 재보고 그 사이로 기준값을 정할 것.
   (근태관리 검증 실측: 진짜 예시 99.5% / 위조 예시 6.7% — 크게 갈리지만 저조도·역광에선 진짜 점수가 내려감)
2. **전처리 설정 변경 금지.** `liveness.ts`의 크롭 배율(4.0/2.7)·80×80·BGR·보간(linear)은 원 모델 학습 조건 재현이다.
   바꾸면 점수가 왜곡된다(보간 하나로 최대 12%p 차이 실측).
3. **한계**: 종이 사진·휴대폰/모니터 화면은 잘 잡지만, 정교한 동영상 재생·3D 가면·딥페이크는 미보장.
   차단용이 아니라 "의심 표시·보조 신호"로 쓰는 것을 권장.
4. **판독 입력 사진은 저장하지 말 것**(개인정보). 점수만 기록하고 원본은 메모리에서 폐기가 기본.
5. 모델 출처: minivision-ai Silent-Face-Anti-Spoofing → yakhyo/face-anti-spoofing ONNX 변환본 (모두 Apache-2.0).
