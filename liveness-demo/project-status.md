## 완료된 기능
- 라이브니스 데모 앱: 웹캠 촬영 → GaonFR 얼굴검출 → MiniFASNet 2종 판독 → 점수·이력 (이번 세션 이전)
- 얼굴 최소 크기 검사(minPercent) + 가이드 타원 + 슬라이더 (이번 세션 이전)
- 판정 방식 3종: 평균 / 둘 다 통과(AND) / 모델별 차등(A·B 다른 기준) — 기본 AND. 이력에 "현재 적용 설정" 표기 (2026-07-11)
- 연속 3장 촬영 + 전 장 통과 판정 — 검출은 첫 장 1회, 동일 바이트 사진 반복 거절 (2026-07-11)
- 질감(망점·모아레) FFT 점수 — 관찰 모드(판정 미반영, 표시만). 실측 결과 진짜/위조 분리 안 됨(진짜 3.8~6.4 / 위조 3.7~5.6) → 판정 미사용 확정, 코드는 재실험용으로 존치 (2026-07-11)
- 시작 기본값 고정: 얼굴크기 35% · 판정방식 AND · 기준값 80% — 밝은/보통 조도 실측에서 오려낸 사진을 잘 막은 조합 (2026-07-11)
- 저조도 밝기 안내: 얼굴이 어두우면 위조 판정 대신 "더 밝은 곳에서" 안내(tooDark). 밝기 기준 슬라이더, 기본 꺼짐(0). lib/quality.ts(faceBrightness) 신규 (2026-07-11)
