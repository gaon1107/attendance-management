## 🔴 반드시 (안 하면 사고)

### 1. 테스트·검증용 계정과 회사 삭제
운영 DB에 아래 계정이 절대 넘어가면 안 된다. **지금은 남겨둔다** — 앞으로 할 수정(특히 교대제·결재선 회귀 테스트)의 검증 데이터라서 지우면 검증 수단이 사라진다.

| 회사 | 계정 | 용도 |
|---|---|---|
| 모의-반려테스트 | `mock-admin@test.local`, `mock-emp@test.local` | 결재 반려 흐름 검증 |
| 모의-교대테스트 | `mock-shift-admin@test.local`, `mock-shift-e1/e2@test.local` | **교대제 회귀 검증(중요)** |
| 가온테크(운영검증) | `qa-admin@test.local`, `qa-bonbu/tim/emp1/emp2/emp3@test.local` | 결재선 3단계 검증 |
| ㈜하늘테크 | `admin@admin.com`, `apply001@naver.com` | 초기 더미 |

**조치**: 운영 DB는 **새로 만들어 시작**하는 것이 원칙(위 계정이 아예 없는 상태). 만약 dev.db를 옮겨 쓴다면 위 계정·회사를 전부 삭제한다.
※ `뉴가온` 회사(`psh01@newgaon.co.kr` 외 6명)는 사장님 실테스트 데이터 — 별도 판단.

### 2. 운영은 개발 서버(`npm run dev`)로 띄우지 않는다
- `근태관리_실행.bat`은 **사장님 PC 개발·테스트 전용**이다.
- 운영은 `npm run build` → `npm run start`(`NODE_ENV=production`)로 띄워야 한다.
- 이유: dev 모드에서는 **세션 쿠키에 `Secure` 표시가 붙지 않고**, 오류 발생 시 내부 파일 경로·소스가 브라우저에 그대로 노출된다.
- (검수 H-3 — 5순위에서 실행 스크립트 분리 예정)

### 3. HTTPS + 리버스 프록시 필수
- 접속 IP를 신뢰하려면 앞단에 프록시(Nginx/IIS)가 반드시 있어야 한다.
- 프록시 없이 그대로 열면 **접속자가 자기 IP를 마음대로 속일 수 있어** 사무실 IP 출근 인증·차단 IP 기능이 무력화된다. (검수 H-1 — 5순위에서 코드 대응 예정)

### 4. 사진 암호화 키(`CLOCK_PHOTO_KEY`) 백업
- `.env`의 이 키를 잃어버리면 저장된 출퇴근 사진을 **영원히 복호화할 수 없다**.
- 운영 이전 시 키를 안전한 곳에 별도 보관한다.

### 5. 얼굴인식 운영 전환
- 현재는 개발 얼굴서버(`gaonfrdev`) + 공개 테스트 계정을 쓰고 있다.
- 실서비스 전 **운영서버에 근태 전용 클라이언트 신규 발급 + 직원 동의 + 위수탁 계약**이 필요하다.
