# 보안 점검 결과 및 조치 (2026-07-07)

> 코드 전체(세션·비밀번호·모든 데이터 변경 동작·모든 URL 화면·위치/IP 판정)를 읽고, 실제로 앱을 돌려 확인한 결과다.
> 대상: `webapp/`. 점검 방식: 코드 정독 + 브라우저 실동작 검증.

---

## 1. 결론 — 가장 중요한 다중회사 격리는 안전

SaaS에서 제일 위험한 "A회사가 B회사 자료를 본다"는 통로를 전부 확인했고, **없다.**

| 점검 항목 | 결과 |
|---|---|
| 남의 회사 직원 URL 직접 입력(`/records/남의id`) | 🟢 차단(내 회사 아니면 404) |
| 관리자 전용 화면에 직원이 접근 | 🟢 차단(출퇴근 화면으로 이동) |
| 모든 조회·수정 쿼리에 회사(companyId) 필터 | 🟢 일관 적용 |
| 비밀번호 저장 | 🟢 scrypt 해시, 원문 없음, 안전비교(timingSafeEqual) |
| 로그인 실패 메시지 | 🟢 이메일/비번 구분 안 함(정보 노출 방지) |
| 비밀키·비밀번호가 코드에 박혀있나 | 🟢 없음(env 사용) |
| GPS 원본좌표·얼굴 원본 저장 | 🟢 저장 안 함(결과만) |
| 로그인 세션 쿠키 | 🟢 httpOnly, sameSite=lax, 운영 시 secure |

## 2. 이번에 코드로 수정한 항목 (2026-07-07, 검증 완료)

1. **로그인 무차별 대입 차단** — 연속 5회 실패 시 10분 잠금. 잠긴 동안엔 맞는 비번도 거부. 성공 시 실패기록 초기화.
   - 파일: `lib` 스키마(User.failedLoginCount·lockedUntil 추가, migration `login_lockout`), `app/actions/auth.ts`
   - 검증: 5회 실패→6회차 잠금 메시지, 잠금 중 정답 비번 거부, 해제 후 정상 로그인까지 브라우저 확인.
2. **사내 IP 대역 매칭 정밀화** — 예전엔 `1.2.3.4` 등록 시 `1.2.3.45`도 통과하던 느슨함 제거. 마침표(.) 경계까지만 대역 인정.
   - 파일: `lib/ip.ts`
3. **만료된 로그인 세션 자동 정리** — 만료 세션은 조회 시 즉시 삭제(DB에 안 쌓임).
   - 파일: `lib/session.ts`
4. **웹 기본 보안 헤더 추가** — 클릭재킹(X-Frame-Options: DENY), MIME 스니핑(nosniff), Referrer 최소화, 위치·카메라 권한 제한, HSTS(HTTPS 강제, 개발 HTTP엔 영향 없음).
   - 파일: `next.config.ts`. 검증: 응답 헤더 5종 확인.

## 3. 배포(서버 임대) 단계에서 반드시 처리할 항목

앱 코드만으로는 완결되지 않고 **서버 설정과 함께** 해야 하는 것들. 실제 인터넷 서비스 전 필수.

- [ ] **접속 IP를 헤더(X-Forwarded-For)로 받는 부분** — 신뢰할 수 있는 프록시(예: 로드밸런서)만 이 헤더를 넣도록 서버를 구성해야 함. 그렇지 않으면 재택자가 "나 사무실 IP"라고 속여 위치확인을 통과할 수 있음. (위치확인은 출근을 막지 않는 '부드러운' 확인이지만, 제품 강점이 *정직한 근무*라 중요)
- [ ] **비밀번호 찾기/재설정** — 이메일 발송 기능 필요 → 이메일 서비스 붙일 때 구현.
- [ ] **HTTPS(암호화 접속) 적용** — 그래야 위 HSTS·secure 쿠키가 실제로 동작.
- [ ] **회원가입/초대 폼의 "이미 가입된 이메일" 메시지** — 남의 가입 여부를 떠볼 수 있는 낮은 수준 정보 노출. 업계 표준상 흔히 허용하나, 필요 시 문구 완화.
- [ ] **로그인 잠금의 임계값(5회/10분) 재검토** — 공격자가 남의 계정을 일부러 잠글 수 있는 소지가 있어(계정 잠금형 방식의 일반적 트레이드오프), 트래픽 보고 조정.

## 4. 코드가 아니라 '결정'이 필요한 항목 (사장님 판단)

- **이메일이 전 시스템에서 하나만** — 지금은 한 사람이 두 회사에 동시에 못 들어감. 로그인 방식(이메일로 로그인)과 얽혀 있어 임의로 못 바꿈. 한 사람이 여러 회사 소속을 허용할지는 제품 결정 사항.
