## Executive Summary

| 관점 | 내용 |
|---|---|
| **문제** | 중소기업 사무직 근태관리는 "무료인데 근태 전문성이 약한 도구"와 "전문적인데 비싸고 복잡한 도구" 사이에 낀 시장이며, 실제 근무시간을 정확히 파악하기 어렵고 법정 기록·보존 의무를 놓치기 쉽다. |
| **해결책** | 얼굴인증(선택형)과 GPS를 함께 제공하는 웹 근태관리 SaaS로, 얼굴검출을 활용해 "정직한 실근무시간"을 자동 산출하고 법정 근로시간 기록·3년 보존을 기본 내장한다. |
| **기능이 주는 체감 효과** | 직원은 원하는 방식(얼굴 또는 GPS)으로 간편하게 출퇴근하고, 관리자는 클릭 한 번으로 실제 근무시간과 법정 증빙 자료를 확인할 수 있다. |
| **핵심 가치** | "무료보다 정확하고, 전문 솔루션보다 쉬운" 중간지대 포지션 — 정직한 실근무시간 + 법규 자동 준수 + 강제하지 않는 얼굴인증. |

---

## 1. 문제 정의

### 1.1 시장의 문제
- 무료 서비스(알밤, 네이버웍스)는 근태 전문성이 약함.
- 전문 서비스(시프티, 플렉스)는 기능이 과잉이고 비쌈.
- 실제로 "일한 시간"(자리비움 제외)을 신뢰도 높게 자동 산출해주는 제품이 드묾.
- 5인 이상 사업장의 근로시간 기록·3년 보존 의무를 놓쳐 과태료 위험에 노출된 중소기업이 많음.

### 1.2 왜 지금인가
- 주 52시간제 등 근로시간 법규 강화로 중소기업의 클라우드 근태 채택이 늘고 있음.
- 국가인권위원회가 "얼굴인식만으로 근태관리하는 것은 위법 소지가 있다"고 판단해, 시장에 "강제하지 않는 얼굴인증" 설계가 필요한 공백이 생김.

---

## 2. 타겟 페르소나

### 페르소나 A — 직원 (사무직)
- 매일 출퇴근을 기록해야 하는 일반 사무직 근로자.
- 원하는 요구: 출퇴근 기록이 번거롭지 않을 것, 개인정보(특히 얼굴)가 함부로 쓰이지 않는다는 확신.
- 우려: 얼굴 인증이 강제되거나 항상 촬영·감시당하는 느낌.

### 페르소나 B — 관리자 (인사/총무 담당자, 또는 대표)
- 5~50인 규모 중소기업의 인사 담당자 또는 대표.
- 원하는 요구: 직원들의 실제 근무시간을 정확히 파악, 법정 기록·보존 의무를 자동으로 충족, 초과근무·지각 관리를 쉽게.
- 우려: 도입이 복잡하거나 비쌀 것, 생체정보 관리로 인한 법적 책임.

---

## 3. 핵심 가치 제안

| 차별점 | 설명 | 경쟁사 대비 |
|---|---|---|
| 정직한 실근무시간 | 얼굴검출(자리 유무 확인)과 얼굴인식(본인 확인)을 혼용해 실제 근무시간을 산출 | 경쟁사가 약한 지점 |
| 법규 자동 준수 | 5인 이상 사업장 근로시간 기록·3년 보존, 생체정보 동의·암호화를 기본 내장 | "과태료 불안" 해소 |
| 강제하지 않는 얼굴인증 | 얼굴인증은 선택형 옵션, GPS 등 대체수단 항상 병행 | 인권위 기준 충족 + 도입 거부감 완화 |

## 4. 범위 (Scope)

### 4.1 In Scope (1차 MVP)
1. 웹 기반 서비스 (반응형, 모바일 브라우저 지원)
2. 회사/직원 계정 관리 (회원가입, 회사 등록, 직원 초대)
3. 출퇴근 인증 — 얼굴인증(선택) + GPS(대체수단, 항상 제공)
4. 얼굴검출+인식 혼용 실근무시간 산출 (구체 방식은 requirements.md의 게이트 참조)
5. 법정 근로시간 기록 및 3년 보존
6. 관리자 대시보드 (근태 조회, 실근무시간 리포트)
7. 생체정보 별도 동의·암호화·접근통제·파기 절차

### 4.2 Out of Scope (2차 이후)
- 메신저 기능
- 파일공유 기능
- 급여 자동계산, 4대보험 연동
- 결재/휴가 관리 등 고급 인사 기능
- 물리 출입통제 연동(NFC, 세콤 등)
- 네이티브 모바일 앱 (1차는 웹만)

## 5. 성공 지표 (KPI)

| 지표 | 목표 (1차 파일럿 기준) | 측정 방법 |
|---|---|---|
| 파일럿 도입 기업 수 | 1~2개사 | 실사용 계약/합의 |
| 출퇴근 인증 성공률 | 95% 이상 | 로그 기반 (얼굴+GPS 합산) |
| 실근무시간 산출 정확도(체감) | 관리자 만족도 조사에서 "신뢰함" 응답 70% 이상 | 파일럿 설문 |
| 법정 기록·보존 기능 사용률 | 100% (자동 적용이므로) | 시스템 로그 |
| 얼굴인증 강제 관련 민원 | 0건 | 파일럿 피드백 |

## 6. 비기능 요건

### 6.1 보안·개인정보 (필수, 법적 가드레일)
- 얼굴 데이터는 생체정보(민감정보)로 분류하여 처리:
  - 일반 개인정보 동의와 **분리된 별도 명시적 동의** 획득 (목적·항목 사전고지 포함)
  - 얼굴 데이터/벡터는 **암호화 저장**
  - 접근통제: 최소 권한 원칙, 접근 로그 기록
  - 퇴사·동의철회 시 **파기 절차** 자동화
  - 1차는 **관리형 얼굴 인증 API 우선 검토** (자가 벡터 저장 최소화)
- GPS 등 위치정보도 개인정보로 취급, 목적 외 사용 금지.
- 얼굴인증은 **직원에게 강제 불가**. 반드시 GPS 등 대체 출퇴근 수단을 함께 제공 (국가인권위 기준).
- 근로기준법 준수: 5인 이상 사업장 근로시간(출퇴근 시각 포함) 기록 및 **3년 보존**.
- 비밀키·비밀번호·인증서는 소스/문서에 기록하지 않음.

### 6.2 성능·가용성
- 출퇴근 인증 응답 시간: 3초 이내 (얼굴 인증 포함)
- 업무시간대(평일 오전 8~10시, 오후 5~7시) 동시접속 대응

### 6.3 사용성
- 비개발자/비전문가인 관리자도 대시보드를 직관적으로 이해할 수 있어야 함
- 직원의 출퇴근 조작은 3클릭 이내 완료
