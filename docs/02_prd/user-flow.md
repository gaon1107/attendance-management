# 사용자 흐름 (User Flow) — 1차 MVP

> 근거: [PRD.md](PRD.md), [requirements.md](requirements.md)
> 참고: 아래 흐름 중 "실근무시간 자동 보정" 단계는 requirements.md §3 게이트 결정에 따라 세부 방식이 달라짐.

---

## 1. 직원 — 최초 가입 및 얼굴 등록 (선택)

```
1. 관리자로부터 초대 이메일/링크 수신
2. 웹에서 계정 생성 (이름, 이메일, 비밀번호)
3. 출퇴근 인증 방식 선택 안내 화면
   - "얼굴인증 사용하기" 또는 "GPS만 사용하기" 선택 가능 (강제 아님)
4. [얼굴인증 선택 시]
   4-1. 생체정보 별도 동의 화면 (목적·보관기간·파기절차 고지) → 동의 체크
   4-2. 얼굴 등록 (카메라로 얼굴 촬영·등록)
   4-3. 등록 완료
5. [GPS만 선택 시]
   5-1. 위치 정보 접근 권한 동의
   5-2. 등록 완료
6. 온보딩 완료 → 메인 화면 이동
```

## 2. 직원 — 출근

```
1. 웹 접속 (또는 모바일 브라우저)
2. "출근하기" 버튼 클릭
3. [얼굴인증 사용자]
   3-1. 카메라로 얼굴 촬영 → 등록된 얼굴과 대조(본인 확인)
   3-2. 성공 시 출근 시각 기록
   3-3. 실패(인식 안 됨) 시 → GPS 방식으로 자동 전환 안내
4. [GPS 사용자]
   4-1. 현재 위치 확인 → 사전 등록된 사업장 반경 이내 확인
   4-2. 성공 시 출근 시각 기록
5. 출근 완료 화면 (오늘 근무 예정시간 안내)
```

## 3. 직원 — 근무 중 (실근무시간 산출, 옵션에 따라 상이)

```
1. 근무 시작 후 자리비움 발생 시:
   [옵션 A 채택 시] "자리비움 시작" 버튼 직접 클릭 → 복귀 시 "복귀" 버튼 클릭
   [옵션 B 채택 시] 시스템이 N분마다 짧게 얼굴 검출 시도 (이미지 미저장, 결과만 기록)
                    → 검출 안 되면 자리비움으로 자동 표시, 직원에게 사전 고지된 방식으로 투명하게 안내
2. 실근무시간은 (퇴근시각 - 출근시각) - 자리비움시간 으로 자동 계산
```

## 4. 직원 — 퇴근

```
1. "퇴근하기" 버튼 클릭
2. 출근과 동일한 방식(얼굴 또는 GPS)으로 본인 확인
3. 퇴근 시각 기록
4. 오늘의 실근무시간 요약 화면 표시 (출퇴근 시각, 자리비움 시간, 실근무시간)
```

## 5. 관리자 — 근태 조회 및 리포트

```
1. 관리자 로그인 → 대시보드 진입
2. 대시보드에서 확인 가능한 정보:
   - 오늘 출근/미출근 직원 현황
   - 직원별 실근무시간 (일/주/월 단위)
   - 지각/조퇴 표시 (P1)
3. 특정 직원 클릭 → 상세 출퇴근 기록(날짜별) 조회
4. 법정 증빙용 리포트 다운로드 (CSV/PDF) (P1)
5. 근로시간 기록은 자동으로 3년간 보존됨 (별도 조작 불필요)
```

## 6. 관리자 — 직원 관리

```
1. 대시보드 → "직원 관리" 메뉴
2. 직원 초대 (이메일 입력 → 초대 발송)
3. 직원 목록에서 정보 수정/삭제
4. 퇴사 처리 시:
   - 계정 비활성화
   - 얼굴 데이터 자동 파기 절차 트리거 (동의 철회와 동일 처리)
```
