## 0. 이 문서의 목적

여기 나온 색상·크기 값은 "화면마다 색이 제각각이 되지 않도록" 미리 정해두는 공통 기준이다.
비개발자도 알아볼 수 있도록 "어디에 쓰는 색인지" 용도를 함께 적었다. 나중에 실제 로고·브랜드 색이 정해지면 primary 색상만 바꾸면 전체 화면에 자동 반영되는 구조를 권장한다.

---

## 1. 색상 (Color)

### 1-1. 용도별 색상

| 용도 | 예시 값 | 어디에 쓰나 |
|---|---|---|
| Primary (주 브랜드색) | `#2563EB` (파랑) | 주요 버튼("출근하기", "가입하기"), 강조 링크 |
| Success (성공/정상) | `#16A34A` (초록) | 출근 완료, 동의 완료, "정상" 상태 표시 |
| Warning (주의) | `#F59E0B` (주황) | 지각, 자리비움, "확인 필요" 배지 |
| Danger (위험/삭제) | `#DC2626` (빨강) | 얼굴 데이터 삭제, 퇴사 처리 등 되돌릴 수 없는 동작 |
| Neutral-900 (본문 텍스트) | `#111827` | 일반 본문 글자색 |
| Neutral-500 (보조 텍스트) | `#6B7280` | 안내 문구, 캡션, 날짜 등 부가 정보 |
| Neutral-200 (테두리/구분선) | `#E5E7EB` | 카드 테두리, 표 구분선 |
| Neutral-50 (배경) | `#F9FAFB` | 페이지 배경, 카드 밖 배경 |
| White (표면) | `#FFFFFF` | 카드, 입력창, 팝업 배경 |

### 1-2. 명도대비(접근성) 기준

- 본문 텍스트와 배경의 명도대비는 **최소 4.5:1** 이상 확보한다 (WCAG 2.1 AA 최소 기준).
- 위 Neutral-900(`#111827`) 텍스트를 White(`#FFFFFF`) 또는 Neutral-50(`#F9FAFB`) 배경에 쓰면 기준을 충분히 만족한다.
- 경고·위험 색(주황/빨강)은 배경색으로만 쓰지 말고 **아이콘이나 텍스트를 함께 표시**해 색맹 사용자도 구분할 수 있게 한다. (예: "⚠️ 지각" 처럼 기호+텍스트 병행)

## 2. 타이포그래피 (Typography)

### 2-1. 글꼴

| 용도 | 글꼴(예시) | 비고 |
|---|---|---|
| 기본 글꼴 | Pretendard (한글), 시스템 기본 sans-serif | 한글 가독성 좋은 무료 글꼴, 라이선스 확인 후 확정 |

### 2-2. 크기 단계

| 단계 | 크기(예시) | 어디에 쓰나 |
|---|---|---|
| Display (가장 큼) | 28px | "실근무시간 8시간 48분"처럼 화면의 핵심 숫자 강조 |
| Heading (제목) | 20px | 화면 타이틀("직원 관리", "내 근태 조회") |
| Body (본문, 기본) | 16px | 일반 본문, 버튼 글자, 표 내용 |
| Caption (보조) | 13px | 날짜, 안내 문구, 부가 설명 |

- 글자 굵기는 기본(Regular)과 강조(Bold/SemiBold) 2단계만 사용해 과하게 다양화하지 않는다.

---

## 3. 간격 (Spacing)

기본 단위 4px 배수를 사용한다 (계산이 쉽고 정렬이 잘 맞음).

| 토큰 | 값 | 어디에 쓰나 |
|---|---|---|
| spacing-xs | 4px | 아이콘과 텍스트 사이 같은 아주 좁은 간격 |
| spacing-sm | 8px | 버튼 안 여백, 입력창 안 여백 |
| spacing-md | 16px | 카드 안 여백, 항목 간 기본 간격 |
| spacing-lg | 24px | 섹션과 섹션 사이 간격 |
| spacing-xl | 32px | 화면 상단/하단 여백 |

---

## 4. 모서리 반경 (Border Radius)

| 토큰 | 값 | 어디에 쓰나 |
|---|---|---|
| radius-sm | 4px | 입력창, 작은 배지 |
| radius-md | 8px | 버튼, 카드 (기본값) |
| radius-lg | 12px | 팝업/모달 |
| radius-full | 9999px (완전 원형) | 원형 아이콘 버튼, 상태 점(●) |

## 5. 버튼 (Button) 기본 상태

| 상태 | 배경색 | 텍스트색 | 비고 |
|---|---|---|---|
| 기본(Default) | Primary `#2563EB` | White | |
| 눌림(Pressed) | Primary보다 약간 어둡게 | White | 터치 피드백 |
| 비활성화(Disabled) | Neutral-200 `#E5E7EB` | Neutral-500 | 필수 동의 체크 전 등 |
| 위험 동작(Danger) | Danger `#DC2626` | White | 삭제·철회 등 |

- 버튼 최소 터치 영역: **가로/세로 44px 이상** (WCAG 2.1 AA 최소 터치 크기 기준). 모바일에서 오조작을 막기 위함.

---

## 6. 입력창(Input) 기본 상태

| 상태 | 테두리색 | 비고 |
|---|---|---|
| 기본(Default) | Neutral-200 `#E5E7EB` | |
| 포커스(Focus) | Primary `#2563EB` | 입력 중임을 명확히 표시 |
| 오류(Error) | Danger `#DC2626` | 오류 문구를 입력창 바로 아래 텍스트로 함께 표시 |

- 입력창 높이도 버튼과 동일하게 최소 44px 확보 (모바일 터치 기준).

---

## 7. 접근성 최소 기준 요약

| 항목 | 기준 |
|---|---|
| 터치 영역 | 버튼·입력창 최소 44×44px |
| 명도대비 | 본문 텍스트 대 배경 최소 4.5:1 |
| 색 단독 사용 금지 | 경고/위험 정보는 색+아이콘/텍스트 병행 |
| 상태 안내 | 카메라 촬영, 위치 확인 등 로딩 상태는 "확인 중..." 같은 텍스트로도 안내(시각 정보만 의존 금지) |

---

## 8. 조정 가능 안내

- 이 문서의 색상 값(HEX 코드), 폰트명, 정확한 픽셀 값은 모두 **예시이며 확정이 아니다.**
- 실제 로고/브랜드 색상이 정해지면 Primary 색상만 교체하면 되도록 설계했다.
- 개발 단계(phase-5-design-system)에서 shadcn/ui 등 컴포넌트 라이브러리에 이 값을 CSS 변수로 옮겨 적용할 예정이다.
