# 화면 목록 (Screen Inventory) — 정보구조/사이트맵

> **작성**: UX/UI 설계 담당 (bkit frontend-architect)
> **작성일**: 2026-07-04
> **근거 문서**: [PRD.md](../02_prd/PRD.md), [requirements.md](../02_prd/requirements.md), [user-flow.md](../02_prd/user-flow.md)
> **상태**: 승인 완료 (2026-07-04) — 결제·요금제 3개 화면을 P1(파일럿 이후)로 조정 반영
> **주의**: 이 문서는 "어떤 화면이 필요한가"만 정리한다. 와이어프레임(화면 뼈대)·색상·컴포넌트 설계는 다음 단계에서 진행한다.

---

## 0. 작성 방식 안내

- 각 화면은 표로 정리했고, 항목은: **화면명 / 목적 / 사용자 / 주요 구성요소 / 우선순위 / 연결 기능(F-ID) / 참조근거** 이다.
- 우선순위: **P0**(1차 MVP 필수) / **P1**(있으면 좋음) / **P2**(2차 이후, 이번엔 안 만듦)
- 참조근거의 "경쟁사 패턴"은 시프티(Shiftee)·플렉스(Flex) 등 기존 근태관리 SaaS의 대시보드 구성 방식을 참고했다 (베끼기가 아니라 "이런 페이지가 보통 필요하더라"는 근거로만 사용).

## 5. 전체 사이트맵 (구조도)

```
[공개 영역]
├─ 랜딩 페이지
├─ 요금제 소개
├─ 회사 회원가입
├─ 로그인 (관리자/직원 공용 → 로그인 후 역할별 분기)
└─ 비밀번호 찾기/재설정 (P1)

[회사 온보딩] (회원가입 직후, 관리자만)
├─ 구독 결제
└─ 회사 초기설정 (근무제·기준시간·사업장 위치 등록)

[관리자 영역] (로그인 후, role=admin)
├─ 대시보드 (메인)
├─ 직원 관리
│  ├─ 직원 목록
│  ├─ 직원 초대
│  └─ 직원 상세/수정
├─ 근태 관리
│  ├─ 근태 현황 조회(전체)
│  ├─ 직원별 근태 상세
│  ├─ 실근무시간 리포트
│  └─ 지각/조퇴 현황 (P1)
├─ 법정 기록
│  └─ 법정 근로기록 조회/내보내기
├─ 생체정보 관리
│  └─ 동의·파기 관리
├─ 근무제·기준시간 설정
├─ 알림 설정 (P1)
└─ 구독·결제 관리

[직원 영역] (로그인 후, role=employee)
├─ (최초 1회) 온보딩
│  ├─ 초대 수락/계정생성
│  ├─ 인증방식 선택 안내
│  ├─ [얼굴] 생체정보 동의 → 얼굴 등록
│  ├─ [GPS] GPS 사용 동의
│  └─ 온보딩 완료 (P1)
├─ 메인/출퇴근 화면
│  ├─ 얼굴인증 촬영 (또는)
│  ├─ GPS 확인
│  ├─ 근무 중 자리확인 안내(옵션 B)
│  └─ 출퇴근 완료 요약
├─ 내 근태 조회
├─ 내 정보/얼굴 재등록·삭제
└─ 지각/휴가 신청 (P1)

[공통/시스템] (전 영역 공통)
├─ 에러 화면 (404/500)
├─ 빈 화면
├─ 알림/이메일 (발송, 화면 아님)
└─ 계정 설정 (비밀번호 변경 등)
```

## 8. 과설계 방지 체크
