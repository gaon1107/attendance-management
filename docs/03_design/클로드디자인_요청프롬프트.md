# 클로드 디자인(claude.ai) 요청문 모음 — 복사해서 붙여넣기용

> 사용법: 아래 블록을 **위에서부터 순서대로** claude.ai 대화창에 복사해 넣으세요.
> **같은 대화 안에서** 이어서 요청해야 스타일이 일관됩니다. (새 대화를 열면 스타일을 다시 알려줘야 함)
> 1번(스타일)을 먼저 넣고 → 2~7번(화면)을 하나씩.

## ① 먼저 — 공통 스타일 잡기 (제일 먼저, 딱 1번)

```
근태관리 웹 서비스의 화면들을 만들 거야. 먼저 공통 디자인 스타일부터 잡아줘.

[컨셉] 중소기업이 매일 업무로 쓰는, 신뢰감 있고 군더더기 없는 기업용 SaaS.
참고 톤: Linear, Notion, 그리고 근태 서비스 Shiftee(시프티)·Jibble(지블)의 깔끔한 대시보드.

[색상]
- 주색(파랑) #2563EB, 성공(초록) #16A34A, 주의(주황) #F59E0B, 위험(빨강) #DC2626
- 본문 글자 #111827, 보조 글자 #6B7280, 테두리 #E5E7EB, 배경 #F9FAFB, 카드 흰색 #FFFFFF

[글꼴/크기] 한글 Pretendard. 큰 숫자 28px, 제목 20px, 본문 16px, 보조 13px. 굵기는 보통/굵게 2단계만.

[규칙] 버튼·입력칸 높이 44px 이상, 모서리 버튼/카드 8~12px. 글자-배경 명도대비 4.5:1 이상.

[절대 하지 말 것 — 중요]
화려한 그라데이션, 과한 그림자, 이모지 남발, 장식용 일러스트, 장난스러운 톤 금지.
"AI가 흔히 만드는 뻔한 랜딩 템플릿" 느낌을 피하고, 실제 업무용 관리도구처럼 담백하게.

[반응형] 관리자 화면은 PC 넓은 화면 기준, 직원 화면은 휴대폰 세로 기준.

이 스타일을 기준으로 앞으로 화면을 하나씩 요청할게.
먼저 이 스타일을 적용한 기본 요소(버튼, 입력칸, 카드, 표) 샘플을 보여줘.
```

## ② 회사 회원가입 화면

```
위 스타일로 "회사 회원가입" 화면을 만들어줘.
- 입력: 회사명, 이메일, 비밀번호
- 큰 파랑 "가입하기" 버튼
- 그 아래 구분선("또는 간편 가입")
- 소셜 가입 버튼 3개(가로 폭 꽉 차게, 각 브랜드 규칙대로):
  · 카카오: 배경 #FEE500, 검정 글자, "카카오로 시작하기"
  · 네이버: 배경 #03C75A, 흰 글자, "네이버로 시작하기"
  · 구글: 흰 배경 + 회색 테두리, 검정 글자, 왼쪽에 구글 로고, "Google로 시작하기"
- 맨 아래 "이미 계정이 있으세요? 로그인" 링크
- 예시값: 회사명 ㈜하늘테크
- 화면 가운데 카드형 폼 하나. 담백한 업무용 톤(소셜 버튼만 브랜드색, 나머지는 스타일 가이드 그대로).
```

## ③ 로그인 화면

```
위 스타일로 "로그인" 화면. 회원가입과 같은 담백한 폼 패턴 재사용.
- 입력: 이메일, 비밀번호
- "로그인" 버튼, "비밀번호를 잊으셨나요?" 링크
- 구분선("또는 간편 로그인") 아래 소셜 로그인 버튼 3개(회원가입과 동일 스타일):
  · 카카오 #FEE500 검정글자 "카카오로 로그인" / 네이버 #03C75A 흰글자 "네이버로 로그인" / 구글 흰배경+테두리+로고 "Google로 로그인"
- 로그인하면 역할(관리자/직원)에 따라 다른 화면으로 간다는 전제(그 분기 화면은 따로 만들 필요 없음).
```

## ④ 관리자 대시보드 (PC 넓은 화면)

```
위 스타일로 "관리자 대시보드"(PC 넓은 화면)를 만들어줘.
- 상단(또는 좌측) 메뉴: 대시보드 / 직원관리 / 근태현황 / 리포트 / 생체정보 / 설정
- 오늘 날짜 표시(2026-07-04 금)
- 카드형 요약 4개: "출근 18명", "미출근 2명"(주황), "지각 1명"(주황), "실근무 평균 8.4시간"
- 아래 "주의가 필요한 직원" 표: 김OO - 지각(09:20 출근), 이OO - 미출근(빨강 배지)
- Shiftee 대시보드처럼 카드 요약 + 표 중심, 여백 적당, 장식 없이 정보가 잘 보이게.
```

## ⑤ 직원 목록/관리 (PC)

```
위 스타일로 "직원 관리" 화면(PC).
- 우측 상단 "+ 직원 초대" 버튼
- 표 컬럼: 이름 / 부서 / 상태 / 인증방식 / 생체동의 / (상세 버튼)
- 예시 행: 홍길동·영업팀·재직중·얼굴인증·동의함 / 김OO·총무팀·초대중·-·- / 이OO·개발팀·재직중·GPS·-
- 상태와 동의는 작은 배지(재직중=초록, 초대중=회색)로.
```

## ⑥ 직원 등록(초대)

```
위 스타일로 "직원 초대" 입력 화면(팝업 또는 오른쪽 사이드 패널 형태).
- 이메일 입력(한 명 또는 여러 명 추가), "초대 발송" 버튼
- 담백하게, 입력 1~2개 + 버튼.
```

## ⑦ 직원 출퇴근 화면 (휴대폰)

```
위 스타일로 직원용 "출퇴근" 화면(휴대폰 세로).
- 상단: 서비스명 + 메뉴 아이콘
- 오늘 2026-07-04(금), 근무 예정시간 09:00~18:00, 현재 상태 "출근 전"
- 화면 아래쪽에 크고 누르기 쉬운 파랑 "출근하기" 버튼(엄지 닿는 위치)
- 맨 아래 보조 메뉴: "내 근태 조회", "내 정보"
- 아주 단순하게, 한 화면에 할 일은 1가지(출근)만 도드라지게.
```

## 다음 단계 — 얼굴·GPS·법적 화면 (복사해서 붙여넣기)

핵심 6개가 마음에 들면, 아래 ⑧~⑯을 **순서대로** 복사해 넣으세요. (법적으로 중요한 강조 문구가 이미 다 들어있어요.)

### ⑧ 인증방식 선택 (직원, 휴대폰)

```
위 스타일로 직원용 "인증방식 선택" 화면(휴대폰 세로).
- 화면 위쪽에 눈에 띄게: "출퇴근 방법을 선택하세요. 둘 중 하나를 꼭 골라야 하는 건 아니며, 나중에 언제든 바꿀 수 있습니다."
- 선택 카드 2개를 똑같은 크기·비중으로(한쪽을 더 강조하지 말 것):
  ① 얼굴인증 사용하기 — "카메라로 본인 확인"
  ② GPS만 사용하기 — "위치로 출퇴근 확인"
- 담백하게. "강제가 아니다"가 핵심.
```

### ⑨ 생체정보 동의 (직원, 휴대폰)

```
위 스타일로 "생체정보 이용 동의" 화면(휴대폰).
- 아래 4가지를 각각 "별도 박스"로 분리해서 보여줘:
  (1) 무엇을 수집: 얼굴 이미지·특징점
  (2) 이용 목적: 본인 확인 및 출퇴근 기록
  (3) 보관 기간: 재직 중 또는 철회 시까지, 목적 달성 시 지체 없이 파기
  (4) 철회 방법: [내 정보] 메뉴에서 언제든 삭제 요청 가능
- 맨 아래 "위 내용에 동의합니다" 체크박스
- "동의하고 계속하기" 버튼은 체크 전에는 회색(비활성), 체크하면 파랑으로 활성화
- 무겁지 않고 읽기 쉽게.
```

### ⑩ 얼굴 등록 (직원, 휴대폰)

```
위 스타일로 "얼굴 등록" 화면(휴대폰). 가운데 카메라 미리보기(원형 가이드),
"원 안에 얼굴을 맞춰주세요" 안내, "촬영하기" 버튼.
촬영 성공 시 "등록 완료! 이제 얼굴로 출퇴근할 수 있어요" 확인 화면.
```

### ⑪ GPS 사용 동의 (직원, 휴대폰)

```
위 스타일로 "위치(GPS) 이용 동의" 화면(휴대폰).
안내: "사업장 반경 이내인지만 확인하며, 이동경로는 추적하지 않습니다."
"위치 권한 허용하기" 버튼.
```

### ⑫ 얼굴 출퇴근 촬영 (직원, 휴대폰)

```
위 스타일로 "얼굴 출퇴근 촬영" 화면(휴대폰).
- 카메라 미리보기 + "확인 중..." 로딩
- 성공: "본인 확인 완료! 출근시각 09:02 기록됨"
- 실패: "얼굴을 확인하지 못했어요" + 버튼 2개를 나란히: [GPS로 전환] [다시 촬영]
  (실패해도 당황하지 않게 'GPS로 전환'을 바로 옆에)
```

### ⑬ GPS 확인 출퇴근 (직원, 휴대폰)

```
위 스타일로 "위치 확인" 출퇴근 화면(휴대폰).
- "위치 확인 중..." 로딩
- 반경 이내: "출근 확인됨, 09:03 기록됨"
- 반경 밖: "사업장 반경 밖입니다. 위치를 다시 확인해주세요" + [다시 시도] 버튼
```

### ⑭ 근무 중 자리확인 안내 — 옵션 B (직원, 휴대폰)

```
위 스타일로 직원 "근무 중" 화면(휴대폰)에 자리확인 안내.
- 근무 시작 후 1회 뜨는 안내 배너: "근무 중 10~15분마다 카메라가 짧게 자리 유무만 확인해요. 사진은 저장되지 않습니다." + "알겠어요" 버튼
- 배너를 닫은 뒤에는 화면 아래에 작게 "자리 상태: 자리 있음 (5분 전 확인)"만 표시(감시받는 느낌 최소화)
- 큰 "퇴근하기" 버튼
```

### ⑮ 출퇴근 완료 요약 (직원, 휴대폰)

```
위 스타일로 "오늘 근무 요약" 화면(퇴근 후, 휴대폰).
- 출근 09:02 / 퇴근 18:05 / 자리비움 15분 / 실근무시간 8시간 48분(가장 크게 강조)
- "수고하셨습니다!" 문구 + "확인" 버튼
```

### ⑯ 내 정보·얼굴 삭제(동의 철회) (직원, 휴대폰)

```
위 스타일로 "내 정보" 화면(휴대폰).
- 이름·인증방식 표시
- "얼굴 다시 등록하기" 버튼
- "얼굴 데이터 삭제(동의 철회)" 버튼(위험 동작 스타일, 눈에 띄되 신중하게)
- 삭제 누르면 확인 팝업: "정말 삭제할까요? 삭제 후에는 GPS 방식으로만 출퇴근할 수 있어요." [취소] [삭제하기]
```

### ⑰ 외출/복귀 (직원, 휴대폰)

```
위 스타일로 직원 "외출/복귀" 기능(휴대폰).
- 근무 중 화면에 "퇴근하기"와 함께 보조 버튼 "외출" 추가
- "외출"을 누르면 작은 시트가 뜸: "외출 사유" 드롭다운(식사 / 외근 / 개인용무 / 기타) + "외출 시작" 버튼
- 외출 중에는 화면에 "외출 중 · 식사 (12:03~)" 상태 표시 + 큰 "복귀" 버튼
- "복귀"를 누르면 외출 종료. 아래 작게 "외출 시간은 실근무시간에서 제외됩니다" 안내
- 담백하게. 사유 드롭다운이 핵심.
```

## 관리자 PC 화면 (추가) — 복사해서 붙여넣기

직원관리·대시보드 외에 관리자가 쓸 PC 화면들입니다. ⑱~㉕를 순서대로 복사해 넣으세요.

### ⑱ 회사 초기설정(온보딩) — 관리자 PC

```
위 스타일로 관리자 "회사 초기설정" 화면(PC 넓은 화면).
- 3단계 마법사, 상단 진행바(●─○─○)
- 1단계: 표준 근무시간(예 09:00~18:00)
- 2단계: 사업장 주소 검색 + 지도 미리보기 + 허용 반경(m) 입력
- 3단계: 5인 이상 사업장 여부(예/아니오) 라디오
- 각 단계 "이전/다음", 마지막 "설정 완료" 버튼
```

### ⑲ 직원 상세/수정 — 관리자 PC

```
위 스타일로 관리자 "직원 상세" 화면(PC).
- 상단 기본정보(이름/부서/직급), 인증방식(얼굴인증 사용 중), 생체정보 동의 상태(동의함·2026-06-01)
- "정보 수정" 버튼, "퇴사 처리" 버튼(위험 동작 스타일)
- 퇴사 처리 누르면 확인 팝업("퇴사 처리 시 생체정보가 자동 파기됩니다")
- 예시: 홍길동·영업팀·대리
```

### ⑳ 근무제·기준시간 설정 — 관리자 PC

```
위 스타일로 관리자 "근무제·기준시간 설정" 화면(PC).
- 표준 근무시간(시작/종료), 사업장 위치·GPS 허용 반경(m)
- 사내 네트워크 등록: 회사 WiFi 이름 / 회사 IP 대역 (PC 출퇴근 위치확인용)
- 실근무시간 자리확인 주기(옵션 B, 예 10~15분) 설정
- "저장" 버튼
```

### ㉑ 근태 현황 조회 — 관리자 PC

```
위 스타일로 관리자 "근태 현황 조회" 화면(PC).
- 상단 필터: 기간(시작~종료), 부서 선택, "조회" 버튼
- 표: 이름 / 날짜 / 출근 / 퇴근 / 실근무시간
```

### ㉚ 비밀번호 찾기 / 재설정 (공개)

```
위 스타일로 "비밀번호 찾기/재설정" 화면(관리자·직원 공용).
★ 로그인 화면과 완전히 같은 컨셉으로: 위에 '근' 로고 + '근태관리' 글자, 가운데 흰 카드(max 440px, 테두리 #E5E7EB, 라운드 12px), 파랑 #2563EB 강조, Pretendard 글꼴, 담백한 업무용 톤. 로그인의 카드·입력칸(높이 44px)·버튼 스타일을 그대로 재사용.

한 흐름을 3단계로 보여줘 (같은 카드 안에서 내용만 바뀌는 형태, 3개 상태를 나란히 보여줘도 됨):

[1단계 · 이메일 입력]
- 제목 "비밀번호 찾기", 안내 "가입한 이메일로 재설정 링크를 보내드립니다."
- 이메일 입력칸 1개 (예시값 admin@skytech.co.kr)
- 큰 파랑 버튼 "재설정 링크 보내기"
- 맨 아래 "← 로그인으로 돌아가기" 링크

[2단계 · 발송 완료 안내]
- 가운데 초록 #16A34A 체크 아이콘, 제목 "메일을 보냈어요"
- 안내 "admin@skytech.co.kr 로 재설정 링크를 보냈습니다. 메일함(스팸함 포함)을 확인해주세요."
- "메일이 오지 않았나요? 다시 보내기" 링크 + "← 로그인으로 돌아가기"

[3단계 · 새 비밀번호 설정] (메일 링크를 눌러 들어온 화면)
- 제목 "새 비밀번호 설정"
- 입력 2개: 새 비밀번호 / 새 비밀번호 확인
- 조건 안내(작게, 보조 글자 #6B7280): "8자 이상, 영문·숫자 포함"
- 두 값이 다르면 입력칸 아래 빨강 #DC2626 안내 "비밀번호가 일치하지 않습니다"
- 큰 파랑 버튼 "비밀번호 변경하기"
- 완료 상태: 초록 체크 + "변경 완료! 새 비밀번호로 로그인하세요" + 파랑 버튼 "로그인하러 가기"

- 이 화면엔 소셜 로그인 버튼을 넣지 말 것. 로그인/회원가입과 카드·여백·글꼴을 똑같이 맞춰 한 세트처럼 보이게.
```
