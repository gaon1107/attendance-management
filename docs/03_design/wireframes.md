# 와이어프레임 (핵심 화면 뼈대)

> **작성**: UX/UI 설계 담당 (bkit frontend-architect)
> **작성일**: 2026-07-04
> **근거 문서**: [screen-inventory.md](screen-inventory.md)(승인됨), [PRD.md](../02_prd/PRD.md), [user-flow.md](../02_prd/user-flow.md)
> **전제**: 실근무시간 = 옵션 B(주기적 얼굴검출, 이미지 미저장) / 얼굴인증 선택형 + GPS 대체수단 병행 / 결제 화면 제외(P1)

---

## 0. 읽는 법

- 화면마다 "화면명 / 기기 / 주요 영역 배치(박스 그림) / 핵심 버튼·입력 / 이동(→)"을 표기한다.
- 박스 그림은 정확한 픽셀 배치가 아니라 "무엇이 어디쯤 있는지"만 보여주는 저해상도 스케치다.
- 반복되는 패턴(목록→상세, 폼 화면 등)은 한 번만 대표로 그리고 이후엔 "동일 패턴 재사용"이라고만 적는다.
- 30개 화면 전부가 아니라 **핵심 흐름 위주**로 그린다. (요청사항 기준)

## 1. 직원 출퇴근 흐름 (모바일 중심)

### 1-1. 인증방식 선택 안내

```
┌─────────────────────────────┐
│  [뒤로]     인증방식 선택      │  ← 상단 타이틀바
├─────────────────────────────┤
│                               │
│  출퇴근은 두 가지 방법 중       │  ← 안내 문구
│  편하신 걸로 선택하세요.        │
│  (둘 중 하나를 반드시 골라야    │
│   하는 건 아니며, 나중에        │
│   바꿀 수 있습니다)             │  ← "강제 아님" 고지 (법적 가드레일)
│                               │
│  ┌─────────────────────────┐ │
│  │ 📷 얼굴인증 사용하기       │ │  ← 선택 카드 1
│  │  카메라로 본인 확인        │ │
│  └─────────────────────────┘ │
│                               │
│  ┌─────────────────────────┐ │
│  │ 📍 GPS만 사용하기         │ │  ← 선택 카드 2
│  │  위치로 출퇴근 확인        │ │
│  └─────────────────────────┘ │
│                               │
└─────────────────────────────┘
```
- 의도: 직원이 부담 없이 방식을 고르게 하고, "강제가 아니다"를 화면 최초 진입 시점부터 눈에 보이게 고지한다.
- 이동: [얼굴인증 사용하기] → 1-2 생체정보 동의 화면 / [GPS만 사용하기] → 1-5 GPS 사용 동의

### 1-2. 생체정보 동의 화면

```
┌─────────────────────────────┐
│  [뒤로]   생체정보 이용 동의   │
├─────────────────────────────┤
│  ┌─────────────────────────┐ │
│  │ 무엇을 수집하나요?        │ │  ← 고지 박스 1: 수집 항목
│  │ - 얼굴 이미지(등록 시 1회)│ │
│  │ - 근무 중 얼굴 검출 결과  │ │
│  │   (있음/없음, 이미지 저장 │ │
│  │    안 함)                │ │
│  └─────────────────────────┘ │
│  ┌─────────────────────────┐ │
│  │ 왜, 얼마나 보관하나요?    │ │  ← 고지 박스 2: 목적·보관기간
│  │ 본인확인·실근무시간 산출  │ │
│  │ 재직 중 보관, 퇴사/철회시 │ │
│  │ 즉시 파기                 │ │
│  └─────────────────────────┘ │
│  ┌─────────────────────────┐ │
│  │ 언제든 철회할 수 있어요   │ │  ← 고지 박스 3: 철회권
│  │ [내 정보] 메뉴에서 삭제   │ │
│  │ 요청 가능                 │ │
│  └─────────────────────────┘ │
│                               │
│  ☐ 위 내용에 동의합니다       │  ← 체크박스 (필수)
│                               │
│      [ 동의하고 계속하기 ]     │  ← 버튼 (체크 전 비활성화)
└─────────────────────────────┘
```
- 의도: 생체정보는 일반 개인정보와 분리된 별도 명시적 동의가 필요하다(법적 가드레일). 체크 전에는 다음 버튼이 눌리지 않게 해 "무심코 동의"를 막는다.
- 이동: [동의하고 계속하기] → 1-3 얼굴 등록

```
┌─────────────────────────────┐

│      │               │       │
│      └───────────────┘       │
│                               │

│                               │
│         [ 촬영하기 ]           │  ← 촬영 버튼

### 1-6. 얼굴인증 촬영(출퇴근)

```
┌─────────────────────────────┐
│  [취소]     본인 확인 중       │
├─────────────────────────────┤
│      ┌───────────────┐       │
│      │               │       │  ← 카메라 미리보기 (자동 촬영)

┌─────────────────────────────┐ ┌─────────────────────────────┐

- 이동: 성공 → 1-8(옵션 B 안내, 최초 1일 1회) 또는 2-2 출퇴근 완료 요약 / 실패-GPS전환 → 1-7

### 1-8. 근무 중 자리확인 안내 (옵션 B)

```
┌─────────────────────────────┐
│  근태관리          [☰ 메뉴]   │
├─────────────────────────────┤
│  ┌─────────────────────────┐ │
│  │ ℹ️ 자리확인 안내           │ │  ← 최초 1회 고지 배너
│  │ 근무 중 10~15분마다        │ │
│  │ 카메라가 짧게 자리 유무만  │ │
│  │ 확인해요. 사진은 저장되지  │ │
│  │ 않습니다.                  │ │
│  │        [ 알겠어요 ]        │ │
│  └─────────────────────────┘ │
│                               │
│   현재 상태: 근무 중 (09:05~) │  ← 평소엔 이 화면(메인과 동일 뼈대)
│                               │
│   자리 상태: 🟢 자리 있음      │  ← 소극적 상태 표시(강조 없이, 작게)
│   (5분 전 확인)                │
│                               │
│      ┌─────────────────┐     │
│      │   퇴근하기        │     │
│      └─────────────────┘     │
└─────────────────────────────┘
```
- 의도: requirements.md에서 확정된 옵션 B의 핵심은 "투명한 사전 고지"다. 배너는 근무 시작 후 처음 1회만 뜨고, 이후엔 화면 아래에 조용히 상태만 표시해 감시받는 느낌을 최소화한다. (사진 미저장 문구를 반드시 유지)
- 이동: 배너 [알겠어요] → 배너 닫힘, 평소 메인/출퇴근 화면 유지. [퇴근하기] → 1-6/1-7 재확인 → 2-2

## 2. 직원 — 내 근태 조회, 내 정보/얼굴 삭제

### 2-1. 내 근태 조회 (목록형 대표 패턴)

```
┌─────────────────────────────┐
│  [뒤로]      내 근태 조회       │
├─────────────────────────────┤
│  이번 달 요약                  │
│  총 근무일 20일 / 평균 8.5시간 │  ← 월간 요약 (상단 고정)
├─────────────────────────────┤
│  07/04(금)  09:02~18:05  8:48 │  ← 목록 행 (반복)
│  07/03(목)  09:00~18:00  8:52 │
│  07/02(수)  09:10~18:00  8:35 │
│  ...                          │
└─────────────────────────────┘
```
- 의도: 날짜별 목록 + 상단 요약이라는 패턴은 관리자 화면의 "근태 현황 조회", "직원별 근태 상세"에도 동일하게 재사용된다 (표만 있고 목록/상세 구조는 동일 패턴).
- 이동: 목록 행 클릭 → 해당 날짜 상세 팝업(자리비움 구간 등, 별도 화면 아님)

---

### 2-2. 내 정보/얼굴 재등록·삭제 (동의 철회)

```
┌─────────────────────────────┐
│  [뒤로]        내 정보          │
├─────────────────────────────┤
│  이름: 홍길동                   │  ← 기본 정보(수정은 관리자 권한)
│  인증방식: 얼굴인증 사용 중      │
├─────────────────────────────┤
│  [ 얼굴 다시 등록하기 ]         │  ← 재등록 버튼 → 1-3 재사용
│                               │
│  [ 얼굴 데이터 삭제(동의 철회) ]│  ← 위험 동작 버튼 (강조색 아님, 명확히 구분)
└─────────────────────────────┘
        ↓ 삭제 버튼 클릭
┌─────────────────────────────┐
│  정말 삭제할까요?               │  ← 확인 팝업 (되돌릴 수 없음 고지)
│  삭제 후에는 GPS 방식으로만     │
│  출퇴근할 수 있어요.            │
│    [ 취소 ]   [ 삭제하기 ]     │
└─────────────────────────────┘
```
- 의도: 동의 철회권을 쉽게 찾을 수 있는 위치에 두되(법적 가드레일), 실수로 누르지 않도록 확인 단계를 거친다.
- 이동: [삭제하기] → 삭제 완료 후 2-1 화면 유지(방식만 GPS로 전환됨을 안내)

│     [ 이전 ]                    [ 다음 ]          │
└───────────────────────────────────────────────┘
        ↓
┌───────────────────────────────────────────────┐
│  3) 5인 이상 사업장 여부     [○───○───●]         │
│     ○ 예 (법정 기록 자동 적용)                    │
│     ○ 아니오                                      │
│     [ 이전 ]                  [ 설정 완료 ]        │
└───────────────────────────────────────────────┘
```
- 의도: 3단계 마법사(Wizard) 형태로, 관리자가 한 번에 필수 설정만 끝내게 한다. 각 단계는 같은 레이아웃(진행 바 + 입력 + 이전/다음)을 재사용한다.
- 이동: [설정 완료] → 3-2 관리자 대시보드

### 3-2. 관리자 대시보드

```
┌──────────────────────────────────────────────────────────┐
│ 근태관리      [대시보드][직원관리][근태현황][리포트][생체정보][설정]│ ← 좌측 또는 상단 메뉴
├──────────────────────────────────────────────────────────┤
│  오늘 2026-07-04(금)                                        │
│  ┌───────────┐ ┌───────────┐ ┌───────────┐ ┌───────────┐│
│  │ 출근 18명  │ │ 미출근 2명 │ │ 지각 1명   │ │ 실근무 평균││  ← 카드형 요약 4개
│  │           │ │  ⚠️ 클릭   │ │  ⚠️ 클릭   │ │  8.4시간  ││
│  └───────────┘ └───────────┘ └───────────┘ └───────────┘│
├──────────────────────────────────────────────────────────┤
│  주의가 필요한 직원                                          │
│  ┌────────────────────────────────────────────────────┐ │
│  │ 김OO - 지각 (09:20 출근)                              │ │  ← 알림 목록
│  │ 이OO - 미출근                                         │ │
│  └────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```
- 의도: 관리자가 로그인 직후 "오늘 뭐가 문제인지"를 카드 4개로 즉시 파악하게 한다(경쟁사 시프티 패턴 참고, screen-inventory.md 근거 동일). 카드 클릭 시 해당 필터가 걸린 근태 현황 조회로 이동.
- 이동: 카드/알림 클릭 → 3-4 근태 현황 조회(필터 적용) / 상단 메뉴 → 각 화면

### 3-3. 직원 관리(목록/초대) — 목록형 대표 패턴

```
┌──────────────────────────────────────────────────────────┐
│  직원 관리                              [ + 직원 초대 ]     │  ← 목록 상단 액션 버튼
├──────────────────────────────────────────────────────────┤
│  이름   부서   상태      인증방식   생체동의               │
│  홍길동 영업팀 재직중    얼굴인증   동의함        [상세>] │  ← 목록 행 (반복)
│  김OO   총무팀 초대중    -         -             [상세>] │
│  이OO   개발팀 재직중    GPS       -             [상세>] │
└──────────────────────────────────────────────────────────┘
```
- 의도: 이 "목록 + 상세 버튼" 패턴은 근태 현황 조회, 생체정보 동의·파기 관리 목록에도 동일하게 재사용된다.
- 이동: [+ 직원 초대] → 초대 폼(이메일 입력, 별도 화면 아니고 팝업/사이드시트) / [상세>] → 3-3-1 직원 상세

#### 3-3-1. 직원 상세/수정 (상세형 대표 패턴)

```
┌──────────────────────────────────────────────────────────┐
│  [< 목록으로]   홍길동 상세                                 │
├──────────────────────────────────────────────────────────┤
│  이름: 홍길동   부서: 영업팀   직급: 대리                    │  ← 기본 정보 영역
│  인증방식: 얼굴인증 사용 중                                  │
│  생체정보 동의: 동의함 (2026-06-01)                          │  ← 동의 상태 표시
│                                                              │
│  [ 정보 수정 ]   [ 퇴사 처리 ]                                │  ← 관리 액션
└──────────────────────────────────────────────────────────┘
```
- 의도: 이 "상세 화면" 패턴은 직원별 근태 상세에도 동일하게 재사용된다(상단 기본 정보 + 아래 내용 영역만 바뀜).
- 이동: [퇴사 처리] → 확인 팝업 → 완료 시 생체정보 자동 파기 트리거 안내(법적 가드레일, user-flow.md §6 반영)

### 3-4. 근태 현황 조회(전체)

```
┌──────────────────────────────────────────────────────────┐
│  근태 현황 조회                                              │
│  기간: [2026-07-01] ~ [2026-07-04]  부서: [전체 ▾] [조회]   │  ← 필터 영역

│  김OO   07/04     09:20  -      -  (근무중)                │
└──────────────────────────────────────────────────────────┘
```
- 의도: 필터(기간/부서) + 목록 조합. 목록 행 클릭 시 3-3-1과 동일한 "상세형" 패턴으로 직원별 근태 상세가 열린다.
- 이동: 행 클릭 → 직원별 근태 상세(3-3-1과 동일 패턴, 근태 기록 중심)

## 4. 공개 화면

### 4-1. 랜딩 페이지 (요약만)

```
┌──────────────────────────────────────────────────────────┐
│  근태관리 로고            [로그인]  [무료로 시작하기]         │  ← 헤더
├──────────────────────────────────────────────────────────┤
│         정직한 실근무시간, 강제하지 않는 얼굴인증             │  ← 핵심 가치 문구 (PRD 근거)
│         [ 무료로 시작하기 ]                                  │
├──────────────────────────────────────────────────────────┤
│  ✔ 정직한 실근무시간    ✔ 법규 자동 준수   ✔ 강제 없는 얼굴인증│  ← 차별점 3가지 요약 카드

```
- 의도: 요약만 그린다(요청사항). 상세 섹션 구성은 이번 단계에서 다루지 않는다.
- 이동: [무료로 시작하기] → 4-2 회사 회원가입 / [로그인] → 4-3 로그인

### 4-2. 회사 회원가입 (폼형 대표 패턴)

```
┌─────────────────────────────┐
│        회사 회원가입            │
├─────────────────────────────┤
│  회사명   [_______________]   │  ← 입력 필드 (반복 패턴)

│  비밀번호 [_______________]   │
│                               │
│      [ 가입하기 ]              │

```
- 의도: 이 "타이틀 + 입력 필드 나열 + 제출 버튼" 폼 패턴은 로그인 화면에도 동일하게 재사용된다.
- 이동: [가입하기] → 3-1 회사 초기설정 온보딩

### 4-3. 로그인 (동일 패턴 재사용)

```

- 이동: 로그인 성공 → 관리자면 3-2 대시보드 / 직원이면 1-4 메인·출퇴근 화면 (단, 최초 로그인 직원은 1-1 인증방식 선택 안내로)

## 5. 이번에 그리지 않은 것 (과설계 방지 확인)

- 요금제 소개, 구독 결제, 구독·결제 관리 — P1(파일럿 이후)이라 제외.
- 지각/조퇴 현황, 알림 설정, 지각/휴가 신청 — P1이라 제외.
- 에러/빈 화면, 계정 설정 — 공통 시스템 화면으로 반복성이 낮아 상세 와이어프레임 생략(필요 시 다음 단계에서 추가 가능).
- 실근무시간 리포트의 그래프·통계, 법정 기록의 CSV/PDF 내보내기 — 화면 내 "추후 제공" 문구로만 표시, 별도 화면 없음.
