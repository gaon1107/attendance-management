- 결재선 설정 · 재택근무 신청 · 출장 신청 · 야간 특근 신청 · 경조사 신청

### 📅 근무 스케줄·규칙 (2)
- 근무 스케줄표 · 관리자 근무 규칙 설정 ⚠️*중복의심(→ #10 근무제 기준시간 설정)*
- → 교대/스케줄은 사무직 우선순위 낮음.

### 🏖️ 휴가·연차·휴게 (2)
- 연차 정산 내역 · 휴게시간 관리

### 💰 급여 (1)
- 급여명세서 조회 (→ #18 급여 연동과 함께 2차)

### 👥 인사(HR) (4)
- 조직도 · 재직증명서 발급 · 교육 이수 관리 · **인사평가 조회** ⚠️*성과·평가는 경쟁조사에서 '제외'로 판단한 영역(다른 시장). 우선순위 최하.*

### 🔒 보안·IP 관리(관리자) (5)
- 관리자 로그인 이력 · IP 기기 접속 로그 · 차단 IP 관리 · 이상 접속 알림 설정 · **실시간 접속 지도** ⚠️*직원 위치 실시간 표시는 '감시'로 보일 수 있어 인권위 리스크. "감시 안 함" 포지셔닝과 충돌 가능 → 만들 때 반드시 재검토.*
- (로그인 이력·IP 차단 등은 **관리자 계정 보안**이라 감시와 무관, 안전)

### 📊 리포트·대시보드 (2)
- 관리자 리포트 · 직원 대시보드

### 🗳️ 설문 (1)
