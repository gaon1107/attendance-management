## 2. AI 티가 나는 5가지 패턴 (전 화면 공통)

### ① 이모지 남용 — 가장 먼저 고칠 것
- 코드 기준 **104개 화면 파일**에 이모지·기호가 들어 있다(⚠ 290회, 🔴 47회, 🔒 20회, 🎨·📢·🎉·💪·🏠·🚗·🏢·📝·🙂·📍 …).
- 특히 **버튼 안 이모지**(🏢 사무실 출근 · 🏠 재택근무 · 🚗 외근 · 📝 근태 정정 승인), **빈 화면 문구**("처리할 알림이 없습니다 🎉", "대기 중인 결재가 없습니다 💪"), **인증방식 선택 카드의 큰 🙂·📍**.
- 문제: ① AI 생성물의 대표 특징 ② 윈도우·아이폰·안드로이드에서 **모양이 제각각**(윈도우는 납작한 이모지) ③ 사이드바는 깔끔한 선 아이콘을 쓰는데 본문만 이모지라 **한 화면 안에서 톤이 둘**.
- 처방: 사이드바와 같은 선 아이콘(SVG)으로 교체. 빈 화면 문구의 🎉·💪는 그냥 삭제.

### ② 설명문 과다 — "개발자 메모가 화면에 그대로"
- 리포트·초과근무 관리·연차정산·설정 화면의 표 아래/위에 **4~6줄짜리 회색 문단**이 붙어 있고, 중간중간 **굵은 글씨 조각**이 섞여 있다.
  - 예) 리포트: "실근무 = (퇴근−출근) − 외출. 근무 중인 기록은 현재 시각까지 계산되며, **퇴근을 찍지 않은 채 하루가 지난 기록은** …" (5줄)
  - 예) 초과근무 관리: ✎ 계산 기준 + ⚠ 법 설명 + ※ 두 개 = 표 위에 4줄.
- 문제: 사용자는 안 읽는다. 그리고 "설명으로 때우는" 방식 자체가 AI 글의 전형이다.
- 처방: 한 줄만 남기고 나머지는 **물음표(?) 도움말 아이콘** 또는 "계산 기준 보기" 접기 안으로.

### ③ 영어 소제목(eyebrow) — "WHY 근태관리", "HOW IT WORKS", "FAQ"
- 랜딩의 각 섹션 위에 작은 파란 영어 라벨. 해외 템플릿 관습이고, 한국어 중소기업 대표가 볼 때 뜻이 없다. 회사 규칙(전문용어·영어 지양)과도 어긋난다.
- 처방: 삭제하거나 한글("왜 필요한가", "도입 절차", "자주 묻는 질문")로.

### ④ 근거 없는 숫자 띠 — "5분 · 3년 · 2가지 · 100%"
- 보라→파랑 그라데이션 띠에 큰 숫자 4개. AI 랜딩의 단골 구성이고, **"평균 도입 소요 시간 5분", "100% 근로기준법 대응"은 증명할 수 없는 말**이다. 신뢰를 깎는 쪽으로 작용할 수 있다(법적 표현 리스크도 있다).
- 처방: 띠 자체를 빼거나, 사실인 것만 남긴다(예: "3년 보관" = 법 기준이라 사실 / "단말기 0원" = 사실).

### ⑤ 일러스트·목업이 실제 제품과 무관
- 히어로의 **3D 카툰 남성 + 떠다니는 시계·핀·얼굴 아이콘**, 직원/관리자 카드의 **흐릿한 폰·태블릿 목업**(화면 안 내용이 실제 앱이 아님).
- 이 부분이 "AI로 만든 사이트"라는 인상을 가장 강하게 준다. 실제 대시보드·출근 화면은 이미 충분히 보기 좋다.
- 처방: 히어로 오른쪽을 **실제 대시보드 캡처(브라우저 틀 씌움)** 로, 직원/관리자 카드는 실제 폰 화면 캡처로.

## 3. 화면별 세부 지적

### 홈(랜딩) — 잘된 점 먼저
- 헤드라인 "정직한 실근무시간, 강제하지 않는 얼굴인증"은 차별점을 한 줄로 말한다. 좋다.
- **"같은 하루, 두 가지 계산" 막대 그래프**(9시간 vs 7시간 20분)가 이 사이트에서 가장 설득력 있는 장면이다. 이런 "실제 작동 설명"을 늘려야 한다.
- 비교표(종이·엑셀 / 지문·카드 단말기 / 근태관리)도 효과적이다.
- 요금 카드 "직원 1명당 월 1,000원" — 단순해서 좋다.

### 홈 — 아쉬운 점
- 상단 로고가 약 40px짜리 "가온" 마크뿐이라 **제품 이름이 화면 어디에도 글자로 없다.** 푸터도 같다. 브랜드 기억이 안 남는다.
- 섹션 순서가 교과서 그대로(히어로→이유→비교→3단계→역할→숫자띠→요금→FAQ→마무리 배너). 틀린 건 아니지만 개성이 없다. 2번 항목(실제 화면)으로 바꾸면 자연히 해결된다.
- 아이콘 칩(보라·하늘색 둥근 네모)의 그라데이션이 "AI 템플릿" 느낌. 단색으로 낮추면 차분해진다.
- 폰(390px)에서 비교표 4열이 빽빽하다 — 실제 폰으로 한 번 확인 권장.

### 로그인 / 회원가입
- 구성 자체는 깔끔하다(카드 하나, 입력 두 개, 큰 버튼).
- **브랜드 불일치:** 랜딩은 "가온" 로고, 로그인은 파란 네모 "근" + "근태관리", 사이드바 맨 위도 같은 "근" 네모(회사 로고 자리). 제품명을 하나로 정하고 세 곳을 맞춰야 한다.
- 회원가입 설명문(마스터 열쇠 비유 3줄 + 노란 경고 박스)이 길다. 가입 버튼 위 경고 박스 하나로 충분.

### 관리자 — 공통 뼈대
- 사이드바: 진한 남색, 활성 메뉴에 파란 세로 바 — 대비·가독성 좋다.
- 그러나 **메뉴가 24개 6묶음**이라 노트북 높이(900px)에서 "인사 정보" 묶음부터 잘린다. 특히 **승인 관리 6개가 전부 같은 ☑ 아이콘**이라 훑어서 구분이 안 된다(휴가·외출·재택·야근·출장). 아이콘을 종류별로 다르게 주면 스캔이 빨라진다.
- 메뉴 이름 표기가 섞여 있다: "휴가승인"(붙임) / "초과근무 관리"(띄움) / "밀린 결재" / "결재이력". 띄어쓰기 규칙 통일 필요.
- 회사명이 길면 "가온테크(운영..." 처럼 잘리고 툴팁이 없다.
- 표가 0~3줄인데도 "페이지 당 행: 100 · 0–0 / 0 · ‹ ›" 페이지네이션이 항상 붙는다. 1페이지 이하면 숨기는 게 깔끔하다.

### 관리자 — 대시보드
- 왼쪽 큰 달력이 화면의 60%를 차지하는데 정보량은 공휴일 2개뿐. 오른쪽 **파란 "실시간 근무 인원" 카드는 위 KPI "현재 근무 중 0명"과 같은 숫자를 두 번** 보여준다. 중복 하나를 빼고 그 자리에 "오늘 미출근 명단"처럼 관리자가 바로 행동할 정보를 두면 효과가 커진다.
- 체험 종료 빨간 배너는 눈에 잘 띈다. 좋다.

### 관리자 — 직원 관리
- **핵심인 직원 목록이 맨 아래(1,500px 아래)에 있다.** 위에 결재방식·부서·직급·초대·직원추가 5개 블록이 먼저 나온다. 순서를 뒤집거나(목록 먼저), 부서·직급·결재방식은 접어 두는 게 맞다.
- 부서 이름 5개가 각각 **화면 폭 전체의 입력칸** 안에 들어 있어 "항상 편집 중인 폼"처럼 무겁다. 글자 + 연필 아이콘으로 가볍게.

### 관리자 — 설정
- 세로 4,600px, **저장 버튼이 8개**(근무제·네트워크·외출사유·얼굴기준·재검토·이상접속·PC-OFF·공휴일·사업장 위치). 어디까지가 한 저장 단위인지 헷갈린다.
- 처방: 상단 탭(근무제 / 출퇴근 인증 / 보안 / 사업장) 또는 왼쪽 목차. 설명문은 2번 처방대로 접기.
- 슬라이더(얼굴 폭·진짜 확률)는 이 화면에만 있는 조작 방식이다. 값 입력칸이 옆에 있어 기능엔 문제없지만, 다른 화면과 톤이 다르다.

### 관리자 — 리포트 · 초과근무 · 연차정산
- 표·KPI 틀은 일관되고 좋다. 문제는 2번(설명문)뿐.
- 리포트 "결근 14일"이 빨간 글씨 — 아직 근무 설정 전 회사에서는 전원 결근으로 보여 관리자에게 불필요한 불안을 준다(표시 로직은 별도 검토 대상, 여기선 지적만).

### 관리자 — 현황판(지도) · 보안 로그
- 지도 화면 구성(지도 + 오른쪽 파란 요약 카드 + 사무실/재택/외근 목록)은 읽기 쉽다.
- 기본 OpenStreetMap 타일이 알록달록해 깔끔한 UI와 따로 논다. 회색조 타일(예: CARTO Positron)로 바꾸면 차분해진다 — 이용약관·비용 확인 필요.
- 로그인 이력 표: 성공/실패 배지, 이름+이메일 2줄 — 잘 만들어졌다. 탭(이상 접속·로그인 이력·접속 로그·차단 IP)도 좋다.

### 직원 — 출퇴근
- **큰 파란 "사무실 출근" 버튼 + 재택/외근 보조 버튼** 구조는 정답에 가깝다.
- 다만 그 위에 안내 배너 2개("홈 화면에 추가", "인증방식을 선택해주세요")가 쌓여 **폰에서 출근 버튼이 화면 중간 아래로 밀린다.** 배너는 1개만, 또는 버튼 아래로.
- 버튼 안 🏢🏠🚗 → 아이콘 교체(1번).

### 직원 — 내 근태
- 표의 14줄이 전부 분홍 배경 + 빨간 "결근". 한 달 내내 빨간 화면은 직원에게 **벌 받는 느낌**을 준다. 배경은 빼고 글자만 빨강, 혹은 "기록 없음"은 회색.
- 폰에서는 표가 가로 스크롤이라 "출근" 열부터 잘린다(이미 B안 후보에 "카드로 접기"가 있다).

### 직원 — 인증방식
- 두 카드가 큰 🙂 / 📍 이모지. 생체정보 동의처럼 **신중해야 할 선택 화면이 가장 가벼워 보인다.** 버튼 문구도 "선택" vs "이 방식으로 선택"으로 다르다. 아이콘·문구 통일.

### 모바일 공통
- 햄버거 메뉴, 카드 2열 접힘, 상단 바 2줄 — 기본 대응은 돼 있다.
- 근태현황(관리자) 폰: 빈 상태 문구 "이 기간에 출…"이 표와 함께 가로로 잘린다. 빈 상태 문구는 표 밖으로 빼야 한다.

## 4. 고치는 순서 제안 (사장님 결정용)

| 순위 | 할 일 | 등급(사규) | 기대 효과 |
|---|---|---|---|
| 1 | 이모지 → 선 아이콘 교체 (버튼·빈 상태·인증방식 카드), 🎉💪 삭제 | 가벼움 | AI 티 제거 효과 가장 큼, 되돌리기 쉬움 |
| 2 | 랜딩 영어 소제목 한글화 + 숫자 띠 정리(근거 없는 수치 삭제) | 가벼움 | 신뢰·법적 표현 리스크 제거 |
| 3 | 긴 설명문 → 한 줄 + 도움말(?)/접기 | 가벼움~중간 | 화면이 "제품"처럼 보이기 시작 |
| 4 | 페이지네이션 1페이지 이하 숨김, 결근 행 분홍 배경 완화, 회사명 툴팁 | 가벼움 | 잔손질 |
| 5 | 히어로·역할 카드의 일러스트 → 실제 화면 캡처 | 중간(이미지 제작) | 랜딩 AI 인상 해소, 정직성 |
| 6 | 제품 이름·로고 통일(랜딩·로그인·사이드바) | **사장님 결정 필요** | 브랜드 |
| 7 | 직원관리 순서 뒤집기(목록 먼저), 설정 탭 분리 | 중간(구조 변경) | 관리자 작업 속도 |
