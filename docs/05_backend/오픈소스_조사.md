# 개발에 쓸 만한 공개 소스 조사 (오픈소스)

> 작성일: 2026-07-04 · 목적: 개발 속도를 높일 **라이선스 열린** 공개 소스 조사
> 우리 조건: Next.js/React · 열린 라이선스(MIT 등) · 근태·GPS·얼굴 관련 · 지금은 내 PC 로컬, 나중에 서버 이전

---

## 1. 결론 먼저 (권고)

| 용도 | 추천 | 이유 |
|---|---|---|
| **앱 뼈대(로그인·대시보드·권한)** | **Next.js SaaS Starter** (공식, MIT) | 우리 기술과 100% 일치, 로그인·역할·활동로그가 이미 완성 → 몇 주 아낌 |
| **GPS 거리·반경 계산** | **Turf.js** (MIT) | 지오펜스(반경 이내 판정)에 딱. 검증된 표준 라이브러리 |
| **얼굴 위변조(라이브니스) 보완** | face-api.js / face-liveness-detector (선택) | 사내 서버가 라이브니스 미지원 → 브라우저에서 눈깜빡임 등으로 보완 가능(선택·나중) |
| 나머지(근태 앱들) | **참고만** | 기술이 다르거나(Flutter/MERN) 라이선스·품질 문제 → 코드 재사용 부적합 |

**한 줄 요약**: **"Next.js SaaS Starter"를 뼈대로 깔고, 그 위에 우리 근태·GPS(Turf.js)·얼굴 기능을 얹는다.** 처음부터 다 만들지 않아 시간이 크게 절약된다.

## 2. 상세 — 후보별 분석

### ⭐ (1) Next.js SaaS Starter — **뼈대로 추천**
- 링크: https://github.com/nextjs/saas-starter (Next.js 공식팀)
- **라이선스: MIT** (상업적 사용 자유)
- 기술: **Next.js + PostgreSQL + Drizzle + shadcn/ui + TypeScript** — 우리가 정한 스택과 일치
- 이미 들어있는 것: **로그인(이메일/비번, 자체 호스팅 — 외부 유료서비스 불필요)**, 팀/사용자 관리 대시보드, **역할 권한(소유자/멤버)**, 활동 로그, 랜딩·가격 페이지(결제는 우리 1차엔 뺌)
- 활성도: **스타 15,900**, 활발함
- 우리에게: **로그인·대시보드·권한을 새로 안 만들어도 됨.** 여기에 근태/GPS/얼굴만 추가.
- 참고: DB가 PostgreSQL이지만 Drizzle은 **SQLite도 지원** → 지금은 내 PC의 SQLite로, 나중에 서버의 PostgreSQL로 **자연스럽게 이전** 가능(우리 계획과 잘 맞음).

### (2) ixartz/SaaS-Boilerplate — 대안(멀티테넌시 강함)
- 링크: https://github.com/ixartz/SaaS-Boilerplate
- **라이선스: MIT**
- 기술: Next.js 16 + React 19 + Drizzle + **shadcn/ui**, **멀티테넌시·역할권한·다국어** 강점
- ⚠️ **주의: 로그인이 "Clerk"(외부 서비스)에 묶임** — 무료 티어는 있으나 외부 의존. 자체 호스팅 로그인은 유료(Pro)에서만.
- 활성도: 스타 7.2k, 최근(2026-07) 업데이트
- 우리에게: 멀티테넌시(회사별 격리)는 참고 좋음. 단 **외부 로그인 의존** 때문에 "내 PC 로컬 우선"엔 (1)번이 더 깔끔.

### (3) Turf.js — **GPS 계산에 추천**
- 링크: https://turfjs.org · https://github.com/Turfjs/turf
- **라이선스: MIT**
- 무엇: 위치 계산 표준 라이브러리. **두 좌표 거리 계산, 반경 이내 판정(지오펜스)** 를 바로 제공
- 우리에게: gps-spec의 "사업장 반경 이내인가" 판정을 직접 안 짜고 이걸로 처리.

### (4) 얼굴 라이브니스(위변조 방지) 보완 — 선택 사항
- face-api.js: https://github.com/justadudewhohacks/face-api.js (**MIT**, 브라우저 얼굴검출·눈깜빡임) — 단 2020년 이후 **관리 뜸함(오래됨)**
- face-liveness-detector: https://github.com/sssxyd/face-liveness-detector (눈깜빡임·고개돌림 등 동작 기반 라이브니스, JS/TS) — 라이선스·품질 **확인 필요**
- 우리에게: 사내 GaonFR가 라이브니스를 못 하므로(보안검토 결정②), **브라우저에서 "눈 깜빡여 주세요" 같은 동작 확인**을 얹어 대리출근을 더 막을 수 있음. **1차 필수는 아니고, 파일럿 후 필요시 검토.**

### (5) 코드 재사용은 부적합 — 참고만
- MadhavPruthi/HR-Geo-Attendance (Apache-2.0): 지오펜스 근태지만 **Flutter+Firebase**(우리와 기술 다름), 얼굴 없음, 비활성 → **개념 참고만**
- very-simple-attendance(MIT), MERN 근태앱들: 기술 스택 다르거나 연습용 → 뼈대(1번)보다 나을 게 없음
- 앞서 본 인턴 프로젝트: **라이선스 없음** → 사용 불가

## 3. 이걸로 개발하면 (그림)

```
[Next.js SaaS Starter] ← 로그인·대시보드·권한 (이미 완성, MIT)
        +
[우리가 추가] 근태 기록 · 실근무시간(옵션B) · 관리자 근태화면
        +
[Turf.js] GPS 반경 판정
        +
[사내 GaonFR 연동] 얼굴 등록·인식·검출  (+선택: 브라우저 라이브니스)
        =
   우리 근태관리 서비스
```

## 4. 주의점
- 오픈소스는 **그대로 쓰기 전에 라이선스(MIT/Apache 등)를 반드시 확인**한다. (라이선스 없는 코드는 사용 금지)
- 뼈대(SaaS Starter)의 결제(Stripe)·불필요 기능은 우리 1차에서 **떼어낸다.**
- 클로드 디자인에서 나온 화면 디자인은 이 뼈대 위에 **우리 톤으로 입힌다**(뼈대 기본 UI를 그대로 쓰지 않음).
