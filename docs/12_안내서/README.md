# 고객사 사용 안내서

고객사에 보내는 **사용 설명서**다. 실제 화면을 캡처해 넣은 HTML 한 장이다.

## 사장님이 보내실 파일

| 파일 | 누구에게 | 내용 |
|---|---|---|
| **근태관리_사용안내서.html** | 고객사 **관리자**(사장님·담당자) | 회원가입 → 처음 설정 → 직원 등록 → 직원 폰 사용법 → 근태 현황 → 승인 → 요금 → 자주 묻는 질문 |
| **근태관리_직원안내서.html** | 고객사 **직원 전체** | 초대 링크 가입 → 인증방식 선택 → 얼굴 등록 → 매일 출퇴근 → 내 기록 보기 |

- 두 파일 모두 **그림이 파일 안에 들어 있다.** 파일 하나만 메일에 첨부해 보내도 그림이 깨지지 않는다.
- 더블클릭하면 브라우저에서 바로 열린다. 휴대폰으로 받아 봐도 읽힌다.
- **인터넷이 없어도 똑같이 보인다.** 글꼴을 바깥에서 받아오지 않는다 — 안내서를 여는 고객사 PC 정보가 외부로 나가지 않게 하려는 목적도 있다.
- 인터넷 링크로도 발행해 두었다(claude.ai 아티팩트). **링크는 기본이 비공개**라, 고객사에 주려면 그 페이지의 [공유] 메뉴에서 먼저 공개로 바꿔야 한다.

## 고칠 때

🔴 **`근태관리_*.html`(출력물)을 직접 고치지 말 것.** 다시 구우면 덮어쓴다.

- **글만 고칠 때** → `src/관리자_사용안내서.html` · `src/직원_사용안내서.html` 수정 → 아래 2번만 실행
- **화면이 바뀌어 그림도 다시 찍을 때** → 1번부터

```
# 1) 화면 다시 찍기 (개발 서버 3000이 떠 있어야 한다)
cd webapp
node scripts/seed-demo.mjs "<아무 비밀번호>"          # 데모 회사가 없으면 먼저 만든다
$env:DEMO_PW = "<그 비밀번호>"                        # 명령 기록에 비밀번호가 남지 않게
node scripts/make-guide-shots.mjs "" ../docs/12_안내서/_shots
Copy-Item ../docs/12_안내서/_shots/*.webp ../docs/12_안내서/src/img/
Remove-Item -Recurse -Force ../docs/12_안내서/_shots   # 2배 크기 원본은 커밋하지 않는다

# 2) 파일 하나로 굽기
node scripts/build-guide.mjs
```

- 캡처 스크립트는 **찍어야 할 36장이 다 나왔는지 스스로 대조**한다. 하나라도 빠지면 빨간 글씨로 알리고 실패로 끝난다(빠진 자리에 옛 그림이 실리는 것을 막기 위해서다).
- 끝에 `✔ 완료 — … 36/36장` 이 나와야 정상이다.
- 굽기 스크립트는 **안내서에 안 쓰인 그림**이 있으면 알려 준다.

## 그림에 들어 있는 회사·직원

전부 **가상의 예시**다. 실존 회사·인물이 아니다.

- 회사: `주식회사 한빛솔루션` (개발 DB에 `isDemo=true`로 들어 있어 홈화면 가입자 수 통계에서 빠진다)
- 직원 10명, 이메일 도메인 `@hanbit.example` — `.example`은 실제로 존재할 수 없도록 예약된 도메인이다
- 사무실 주소·IP도 문서용으로 예약된 값이다

데모 데이터를 지우려면: `cd webapp && node scripts/seed-demo.mjs --undo`
(지우면 다음에 그림을 다시 찍을 때 처음부터 만들어야 한다. 그냥 두어도 실서비스에 영향은 없다.)

## 알려진 한계

- **얼굴 등록 화면의 초록색 네모**는 카메라가 없는 환경에서 찍어 색만 나온 것이다. 실제로는 본인 얼굴이 보인다. 안내서 본문에 그렇게 적어 두었다. 사장님이 직접 폰으로 찍은 화면을 주시면 그 그림으로 교체하면 된다.
- **결제 화면은 없다.** 요금 안내까지만 넣었다(결제 기능 미구현).
