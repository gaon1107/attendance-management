프로젝트 루트(`C:\Users\주인님\Desktop\신사업 아이디어\근태관리\`)에 시장조사 문서가 순차적으로 쌓이고 있다.

- `01_시장경쟁사_조사보고서.md` (2026-06-30) — 1차 사업 방향 검증용. 경쟁사 5곳(시프티/플렉스/네이버웍스/알밤/타임인아웃) 출퇴근 인증방식·요금·법적 리스크(인권위 얼굴인식 강제금지, 개인정보보호법 민감정보, 근로기준법 3년보존) 중심.
- `02_경쟁서비스_분석.md` (2026-07-04) — 서비스 범위(P0/P1/2차/제외) 판단용. 시프티·지블(Jibble)·하이웍스·플렉스타임 비교. 12개 기능을 P0~제외로 분류한 표가 핵심 산출물.
- `03_경쟁서비스_전체기능_조사.md` (2026-07-05) — 근태 외 부가서비스 전체 지형(스케줄/휴가/전자결재/HRIS/성과/커뮤니케이션/그룹웨어/출입통제/프로젝트관리/API연동/분석/기타 12범주) 매트릭스. 그리팅(Greeting), 에버타임(EverTime) 신규 발견. 02번 문서의 일부 판단(전자결재를 2차→P1 격상, 분석/인사이트·출입통제API 2차 신규 추가)에 대한 수정 제안 포함 — 사장님 확인 대기 중.

**Why**: 각 문서가 서로 다른 목적(방향성 검증 → 범위 확정 → 부가기능 지형)을 가지므로, 새 조사 요청 시 이미 다룬 내용과 중복하지 않으려면 이 세 문서를 먼저 확인해야 한다.

**How to apply**: 향후 시장조사/경쟁사 조사 요청이 오면 반드시 01·02·03을 먼저 Read하고 "이미 아는 것"과 "새로 조사할 것"을 구분할 것. 특히 03번 문서 4번 섹션(우리 관점 판단 초안)에 사장님 승인 대기 중인 항목이 있으므로, 관련 후속 대화에서는 승인 여부를 확인해야 한다.
