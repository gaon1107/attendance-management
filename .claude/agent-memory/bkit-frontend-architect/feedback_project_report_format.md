이 프로젝트(근태관리 SaaS)는 CLAUDE.md §5에서 모든 직원(에이전트)이 작업을 마칠 때 반드시 아래 4줄 형식으로 보고하도록 정해두었다:
```
## 완료 작업
## 생성 파일
## 위험 요소
## 다음 단계 제안
```

**Why**: 총괄 PM(비개발자 사장님)이 여러 에이전트의 산출물을 일관된 형식으로 빠르게 검토·승인하기 위한 프로젝트 규칙(CLAUDE.md §3 "승인 게이트" 운영과 맞물림).

**How to apply**: 이 프로젝트에서 작업할 때는 다른 형식(예: 자유 서술형 요약)으로 마무리하지 말고 항상 이 4줄 헤더를 사용한다. 과설계 방지 원칙과 함께 매 산출물에 "요청하지 않은 화면/기능을 추가하지 않았다"는 확인도 위험 요소 또는 완료 작업 항목에 자연스럽게 녹여 언급하면 좋다.
