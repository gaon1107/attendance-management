얼굴인식 처리는 사내 GaonFR 서버(뉴가온)에 위탁하는 구조다. GaonFR는 제3자 제공이 아니라 **처리 위탁(수탁자)** 이다 → 제3자제공 동의는 불필요하나 위탁 요건 이행 필요.

**Why:** 개인정보보호법 §26. 근태 SaaS는 SaaS(우리)→고객사(회사)→직원의 3자 구조라, 직원 개인정보 1차 처리자는 고객사(회사)이고 우리·GaonFR는 회사의 수탁자(재위탁) 가능성이 높다. 즉 "회사→우리(수탁)→뉴가온(재위탁)". 재위탁에는 원위탁자(회사) 동의 필요, 고지 주체는 회사.

**How to apply:** 얼굴 관련 동의서·처리방침·계약을 다룰 때 이 재위탁 구조를 전제로 판단. 우리 제품은 회사가 위탁 의무를 쉽게 이행하도록 동의서/처리방침/위탁현황 템플릿을 내장 제공해야 한다. 정확한 3자 구조 법적 정리는 변호사·개인정보 전문가 확인 권장(아직 위수탁 계약 미체결).

식별자 매핑(절대 임의변경 금지): GaonFR `FaceId`=직원 id 문자열, `Group`=회사(테넌트) 식별자(=company.group_key). 우리 DB는 얼굴 원본/특징값 미보관, 참조·동의·파기로그만. 관련 [[security-open-decisions]].
