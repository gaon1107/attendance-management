docs/08_security/review.md 검토 결과, 아래 항목이 사장님 판단 대기 상태다(2026-07-04 기준).

**Why:** 이 프로젝트는 생체정보(얼굴)+위치정보가 얽혀 법적 판단이 핵심이며, 보안검토가 완전한 결론이 아니라 "판정+선택지+권고"로 끝났다. 최종 결정은 사장님 몫이고 전문가 자문이 전제다.

**How to apply:** 향후 이 미결정 항목이 결정되면 review.md와 이 메모를 갱신한다. 결정 전에는 어느 방향으로도 확정된 것처럼 구현/설계하지 않는다.

핵심 미결정(각 review.md의 🚦 결정항목):
1. **옵션 B(근무 중 주기 얼굴검출)** — "이미지 미저장·있음/없음만"이 생체정보 규제를 실제 완화하는지 단정 불가. 여전히 민감정보 처리로 볼 여지 큼. 유지/축소(옵션A)/빈도완화 중 결정 + 개인정보 전문가 자문 필수. (requirements.md §3에서 옵션 B로 잠정 확정했으나 "보안검토 재확인" 조건이 걸려 있었음)
2. **라이브니스** — GaonFR가 라이브니스 미지원. MVP 조합(실시간촬영+nonce+기기바인딩+GPS동시+실패제한)은 흔한 대리출근만 억제, 정교한 위조는 못 막음. 파일럿은 웹 조합으로 수용 권고, 네이티브앱/전문엔진은 데이터 기반 후속 결정.
3. **GPS 원본좌표 보관** — 기본 미저장 권고. 분쟁대응 필요 시 30~90일 한정. 3년 전체보관은 비권고.
4. **GPS 보조확인 정책** — 정책 B(GPS 또는 WiFi/IP) 권고, IP는 참/거짓만 저장.

전제: 파일럿 확대 전 개인정보 전문가·노무사 자문 1회 강력 권고. 관련 [[gaonfr-entrustment-structure]].
